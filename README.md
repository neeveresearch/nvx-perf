# The Perf Repository

This repository contains apps and programs that benchmark the various areas of X Platform 

## Building the repository
1. Ensure Maven is installed
2. Ensure you have a valid X Platform license (see https://docs.neeveresearch.com/display/TALONDOC/Working+with+X+Platform+Licenses)
2. Clone this repository
3. Run mvn install

## The Modules
The following lists and describes the modules in this repository

### nvx-perf-messages
This module defines the messages used by the modules in this repository
